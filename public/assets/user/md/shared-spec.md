# shared-spec

Keep the product's shared specifications here using
[OpenSpec](https://github.com/Fission-AI/OpenSpec). These specifications describe behavior and
requirements that need to stay consistent across the API, application, and documentation projects.

Within this shared workspace, OpenSpec keeps current specifications in `openspec/specs/` and proposed
changes in `openspec/changes/`. See the
[OpenSpec getting-started guide](https://github.com/Fission-AI/OpenSpec/blob/main/docs/getting-started.md)
for its structure and workflow.
