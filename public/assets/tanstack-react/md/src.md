# src

**Path:** `src`\
**Role:** Required: application source

## Purpose

Application code for a TypeScript React application built with TanStack Start and Router.

## Guidelines

Route files compose screens; feature modules own domain behavior; shared modules contain reusable UI and utilities. Server-only modules must stay behind server execution boundaries.
