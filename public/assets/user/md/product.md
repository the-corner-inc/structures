# Product

A product groups multiple related projects, such as an API, an application, and a documentation site.
Each project can live in its own repository and have its own development and release workflow.

- `shared-spec` holds OpenSpec specifications shared across the product's projects.
- `shared-assets` holds assets reused across those projects.
- `product-api` contains the backend API project.
- `product-app` contains the application project.
- `product-docs` contains the documentation project.

Replace `product` in the project names with your product's name.
